# BENS_WEB_SITE

## Deployment

This is a static site (HTML/CSS/JS) hosted on Cloudflare Workers. The `wrangler.jsonc` in the repo root configures Cloudflare to serve the root directory as static assets.

- **Production branch:** `main` — Cloudflare only deploys to production from `main`
- **Push changes directly to `main`** — do not create feature branches unless specifically asked. This is a simple personal site, not a team project, so feature branches just add friction.
- If you must use a branch, merge it to `main` and push before considering the work done.
